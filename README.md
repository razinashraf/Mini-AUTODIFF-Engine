# Mini-AUTODIFF-Engine

A tiny automatic differentiation engine built completely from scratch in Python.

Features
--------
✔ Computational Graph
✔ Reverse-mode Automatic Differentiation
✔ Backpropagation
✔ Topological Sorting
✔ Operator Overloading

Current Status
--------------
Version 1:
- Scalar Value class
- Addition
- Multiplication
- Automatic gradient propagation
